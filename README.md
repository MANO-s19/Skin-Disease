# Deep Learning-Based Automated Detection and Classification of Skin Disease

## Overview
This project focuses on automating the detection and classification of skin diseases using deep learning techniques and medical image datasets.

## Goal
To develop a CNN-based model capable of identifying and classifying different skin diseases from clinical images.

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- CNN

## Features
- Image preprocessing
- Data normalization
- Image augmentation
- CNN model training
- Disease classification
- Performance evaluation

## Workflow
1. Dataset collection
2. Image preprocessing using OpenCV
3. Model development using CNN
4. Model training and evaluation
5. Prediction and classification

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- Confusion Matrix

## Future Improvements
- Improve dataset size
- Enhance model accuracy
- Deploy as a web application
